Java has also mainly 3 types of loops like other programming languages..

1. for loop
condition check before execution
Syntax:

for(initialization; condition; updation){
    // code
}

2. while loop
condition check before execution
Syntax:

initialization
while(condition){
    // code
    updatation
}

3. do - while loop
condition check after execution (runs at least once)
Syntax:

initialization
do{
    // code
    updatation
}
while(condition);

OTHERS:-
1. Nested loop
-> Ek loop ke andar dusra loop

2. Break
-> break → loop ko turant stop kar deta hai.

3. Continue
-> continue → current iteration skip karta hai aur next iteration pe chala jata hai.

4. for each loop
-> Purpose: Array ya collection ke elements iterate karne ke liye.
Syntax:
for(type variable : array){
    // code
}
