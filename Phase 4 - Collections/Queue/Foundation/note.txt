Queue = FIFO | First In First out
jo pehle aaya, wahi pehle niklega.

Core Concept:
Enqueue (insert) → element rear (end) se add hota hai
Dequeue (remove) → element front (start) se nikalta hai

--------Diagram--------
Initial:
Front -> [   ] <- Rear


After Enqueue 10:
Front -> [10] <- Rear


After Enqueue 20, 30:
Front -> [10] [20] [30] <- Rear


After Dequeue:
(remove 10)

Front -> [20] [30] <- Rear
